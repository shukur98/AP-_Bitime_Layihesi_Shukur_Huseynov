# Məhsul bug-ları

Bu təqdimatda nəzərdən keçirilən nəticələr əsasında **təsdiqlənmiş backend məhsul bug-ı qeydə alınmayıb**. Bu, API-nin qüsursuzluğuna təminat deyil. Test kodundakı və ya lokal mühitdəki problemlər məhsul defekti kimi təqdim edilmir.

`Bug_Register.csv` yalnız təkrarlana bilən məhsul qüsurları üçündür. Bug qeydində request, header-lər (token gizlədilməklə), body, test-case ID, expected/actual response, severity, execution evidence və retest statusu göstərilməlidir.
